# Pomodoro Garden

Android向けの、小さなポモドーロタイマー。React Native / Expo / TypeScriptで学びながら作る試作です。

## 今回作ったもの

- 集中25分、小休憩5分、長い休憩15分
- 開始、一時停止、再開、リセット
- 残り時間を円形60本／直線30本のバーで表示。設定で切り替え、表示形式を端末内に保存。直線は横画面、円形は縦画面
- 集中4回の完了後に長い休憩へ移動。次の区間は手動開始
- 3種類のグラデーション背景と、Androidの写真ピッカーから選ぶ背景写真
- 写真選択後の自由な切り取り
- 縦画面／横画面ごとの背景設定と端末内保存。写真はアプリ専用領域へコピー
- スクロールなしのメイン画面。表示形式と背景は設定モーダルで変更
- 画面表示中の完了メッセージと振動

## 開発環境

Expo SDK 57 / React Native 0.86 / React 19.2 / TypeScript 6 を使用します。Expo公式テンプレートとSDK同梱の互換バージョン情報に合わせています。

```bash
npm ci
npm run typecheck
npm test
npx expo install --check
EXPO_UNSTABLE_TUNNEL_V2=1 npx expo start --tunnel
```

クラウドの開発サーバーとスマホは同じLANにいないため、Expo Goで試すには通常トンネルURLが必要です。Expo Go 57に合わせてSDK 57を使用しています。Android実機のExpo Goで起動・動作を確認済みです。同じスマホに表示されたQRコードはカメラで読み取れないので、実際に出力されたExpoリンクで開きます。使用するExpo Goの対応SDKも確認してください。

トンネルが利用できない場合は、Expoアカウントを使ったEAS Buildでテスト用APKを作ります。アカウント接続とビルド枠の確認は未実施です。

```bash
npx eas-cli build:configure
npx eas-cli build --platform android --profile preview
```

APKの作成・署名・配布設定は別途確認が必要です。Google Playへの公開は今回の範囲に含めていません。

## アプリの制約

- Androidのロック中や、アプリを閉じている間の通知は未実装です。
- 実行中のタイマーはメモリ上に保持します。アプリが生きていれば、復帰時に終了時刻から残り時間を再計算します。OSによる終了や再起動では初期化されます。
- 完了区間の自動連続実行は行いません。画面を閉じたまま集中回数が増え続けるのを防ぎます。
- 集中回数は起動中の累計です。日別集計・永続化は未実装です。
- 既定の背景は写真ではなくグラデーションです。ネット接続や画像のライセンスに依存せず試せます。

## コードの読み方

- `App.tsx`: スマホ画面、ユーザー操作、写真選択、背景設定の保存
- `src/timer.ts`: 時間計算と区間の切り替え。Androidに依存しない部分
- `src/timer.test.ts`: 中断からの復帰、一時停止・再開、4回ごとの長い休憩を確認
- `app.json`: アプリ名やAndroidの識別子。配布前に識別子を確定する
- `eas.json`: APK作成用の基本設定

## スマホで確認する項目

1. 開始 → 一時停止 → 再開 → リセット
2. 進行中に別の区間を選び、確認ダイアログでキャンセル／切り替え
3. 背景色を変更し、再起動して設定が戻るか確認
4. 写真選択のキャンセル・選択・再起動後の表示を確認
5. 画面をロックし、数分後の復帰時に残り時間を確認
6. 実機テスト時のみ時間を短縮して、完了メッセージと4回後の長い休憩を確認
